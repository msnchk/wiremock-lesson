В качестве реального API использовала сайт-тренажер https://reqres.in/ .

Три уровня тестов:
1) Mock-тесты — с заглушками WireMock;
2) Proxy-тесты — если нет соответствующей заглушки, запрос проксируется на реальный API;
3) Тесты на реальном API.

Запуск всех тестов:
```
mvn test -Dtest=SequentialTestSuite
```
